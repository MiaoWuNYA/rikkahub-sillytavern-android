# 快速上手：5 分钟内发送第一条 AI 消息

本指南帮你尽快完成第一次对话。你需要一台安卓设备、已安装的华灯，以及至少一个 AI 服务商的 API 密钥。如果还没有密钥，先去对应服务商注册。

## 1. 下载并安装华灯

从 [GitHub Releases](https://github.com/MiaoWuNYA/rikkahub-sillytavern-android/releases/latest) 下载最新 APK 安装。安装完成后从主屏幕打开华灯。

## 2. 打开设置并添加服务商

进入 **设置 → 提供商**。列表里预设了常见服务商，直接进入填写密钥即可；如果用的是自建中转或其他平台，点右上角新建一个提供商。

## 3. 输入 API 密钥与接口地址

把 API 密钥粘贴到 **API Key** 字段。使用非官方中转时，还需填写提供商的 **Base URL**。

::: warning 保管好密钥
密钥只保存在你的设备本地，只会发送给你配置的服务商。不要分享，也不要粘贴到不受信任的应用中。
:::

## 4. 添加模型

进入提供商详情页，在底部**模型**一栏添加模型。多数服务商支持一键拉取模型列表，勾选即可；不需要的模型侧滑删除。

模型可以随时在对话底部的模型选择器里更换，这里的配置只是起点。

## 5. 配置默认模型

回到 **设置 → 默认模型和提示词**，为对话以及标题、翻译、上下文压缩、OCR 等辅助功能分别选择模型。辅助功能建议选速度快、价格低的模型。

## 6. 发送第一条消息

返回主界面，新建对话，选好模型，输入消息发送。回复会实时流式输出——大功告成。

::: tip 开场白建议
可以用「介绍一下你能帮我做什么」作为开场白。应用默认不内置身份类系统提示词，模型对「你是什么模型」的回答并不准确，这是大模型原理所致，可在助手里自行设置。
:::

## 装好之后，再加点东西

- **导入第一个角色卡**：聊天抽屉点**助手** → 点右上角**新建助手**（加号按钮）→ 弹窗中选择**导入酒馆角色卡 (PNG / JSON)**，内嵌世界书和预设自动带进来。见[角色卡](/tavern/character-card)。
- **导入酒馆资产**：世界书、预设、正则脚本、快速回复在 **设置 → 扩展管理** 导入。见[预设·正则·快速回复](/tavern/preset-regex)。
- **添加插件**：**设置 → 插件管理** 导入 ZIP 即可，内置插件开箱可用。见[插件](/extensions/plugins)。
- **换个酒馆主题**：**设置 → 偏好设置 → 主题 → 聊天外观自定义** 中一键导入酒馆美化主题。见[美化主题](/tavern/theme)。

## 从 Chatbox 或其他通用客户端换过来？

基础体验完全对齐（多供应商、流式输出、Markdown / LaTeX / 代码高亮、对话导出、数据备份），之上多出一整层：

| 你熟悉的 | 华灯额外提供 |
| --- | --- |
| 多供应商接入、流式对话 | 同样有，另支持 Anthropic / Gemini 原生协议与中转站病态自动修复 |
| 对话历史 | + 语义记忆 / 三层记忆，AI 跨会话记住你，无需手动粘贴背景 |
| 每轮全文发送，长对话越来越贵 | + [提示词前缀缓存优化](/memory/cache)，长对话 token 成本大幅下降 |
| 单一界面 | + [酒馆兼容](/tavern/character-card)（角色卡 / 世界书 / 预设 / 正则 / 主题按官方语义导入） |
| 无扩展机制 | + [QuickJS 插件系统](/extensions/plugins) + 30 个设备工具 + 微信 / QQ Bot |
| 文字聊天 | + [语音 / 视频通话](/extensions/speech)（豆包 TTS 2.0 + 火山 ASR） |
| 数据同步到云 | 数据全部**本地存储**，S3 / WebDAV 备份自选 |

不需要任何「酒馆」概念也能当纯聊天客户端用——先按普通 AI 客户端上手，想要时再导入角色卡。
