# 生活空间：六个面板记下你的日常

生活空间是 AI 参与记录的日常面板集：身体、日程、备忘、音乐与共读。数据存在本机，AI 通过工具读写。

## 打开方式

聊天页**左侧抽屉**里，文件夹条**右侧的竖向图标列** → **生活空间**。

## 让 AI 调用这些功能

**AI 能不能读写生活空间，取决于工具是否在助手上开启**：到 **助手详情 → 本地工具**，打开**「生活空间」**开关，`life_*` 系列工具才会注册给该助手。开关关闭时工具不注册——AI 调不到，也不占上下文；不用时建议关闭以节省 token。

**设置 → 华灯设置 → 兼容与辅助** 里的**清爽简洁模式**开启后，抽屉入口隐藏、对应工具同样不再注册。

## 六个面板

| 面板 | 记什么 |
| --- | --- |
| **今日** | 身体感受或想让 AI 知道的事 |
| **周期与身体** | 健康周期记录，AI 可据此给出体贴的提醒 |
| **备忘录** | 计划或想法，随手记 |
| **日历提醒** | 时间、地点和需要 AI 提醒的事情，颜色分类 |
| **一起听** | 歌手、故事或一起听歌的回忆 |
| **共读书架** | 阅读进度、原文、批注以及想问 AI 的问题 |

## 与 AI 的联动

对话中 AI 可通过 `life_*` 系列工具读写各面板——说「我今天有点头疼」它会记进今日面板；「帮我在周六的日历放一个提醒」会真的写进日程。支持从 TXT 导入历史记录。

::: tip
生活空间的记忆与[记忆系统](/memory/memory)的跨窗口生活流联动：AI 对你日常的了解越久越准。
:::
