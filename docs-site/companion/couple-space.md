# 情侣空间：和 AI 恋人的小家

把某个助手绑定为「恋人」后解锁的关系空间：动态、日记与纪念日，AI 都会真的参与——不是摆设。

## 打开方式

聊天页**左侧抽屉底部** → **情侣空间**。

## 让 AI 调用这些功能

界面入口与 AI 工具是两回事——**AI 能不能读写情侣空间，取决于工具是否在助手上开启**：

- 到 **助手详情 → 本地工具**，打开**「生活空间」**开关（情侣空间绑定后，共读日记与纪念册工具会一并加入）；
- 开关关闭时这些工具**不会注册**：AI 调不到对应功能，请求里也不带这些工具定义——不用时关闭即可节省上下文 token；
- 另外 **设置 → 华灯设置 → 清爽简洁模式** 开启后，会从两个层面同时隐藏：抽屉入口消失 + 对应工具不再注册。

## 绑定恋人

第一次进入选择你的恋人（从已有助手中挑选）并设置**恋爱开始日期**——绑定后，兔眠空间、我们的日记和纪念日都归属你们两个人。

## 三个板块

- **兔眠空间**：双方都能发动态，AI 会在评论区**真的回复**；
- **我们的日记**：共同的书签日记，可以请 AI 写回信（「问 TA」）；
- **纪念日**：按类别（生日 / 恋爱 / 承诺 / 旅行 / 回忆）收藏重要日子，自动计算倒数天数与周年，支持收藏与「未来 30 天」筛选，封面主题可换（奶油 / 森林 / 薰衣草 / 午夜 / 玫瑰绒）。

## 与 AI 的联动

绑定的恋人在对话中可以通过 `shared_*` / `*_couple_space` 系列工具读写这些内容——你在聊天里说「记一下我们今天一周年」，纪念地里真的会多一条。

::: tip
想只把华灯当工具用？开启**清爽简洁模式**即可一键隐藏全部娱乐入口，界面回到干净的聊天客户端。
:::
