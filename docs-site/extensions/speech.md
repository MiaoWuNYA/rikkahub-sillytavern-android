# 语音与通话：豆包 TTS + 火山 ASR

配置一个火山引擎 Agent Plan API Key，同时驱动语音输入与语音输出；配合语音 / 视频通话，像打电话一样对话。

## 配置步骤

1. 前往 **设置 → 模型与服务 → 模型与服务 → 语音服务**；
2. 选择豆包 TTS，填入火山引擎 **Agent Plan** 的 API Key（`ark-xxx` 格式）；
3. 选择音色与格式；ASR（语音识别）使用同一个 Key，无需重复配置。

::: info Agent Plan 与标准控制台
Agent Plan 的 `ark-xxx` 密钥只在 `/api/v3/plan/` 专属路径有效——应用默认已指向该路径。使用标准控制台密钥的用户，可在设置中把接口路径改回官方地址。
:::

## 音色

内置 14 个豆包 2.0 音色预设（`seed-tts-2.0` 资源）：

| 预设音色 |
| --- |
| 灿灿 2.0（默认）· 快乐小东 2.0（豆包同款）· 甜美桃子 2.0 · 甜美小媛 2.0 · 清新女声 2.0 |
| 高冷御姐 2.0 · 爽快思思 2.0 · 撒娇学妹 2.0 · 俏皮贫女 2.0 · 婆婆 2.0 |
| 佩琪 2.0 · Sofie 2.0 · 鸡汤女 2.0 · 米仔 2.0 |

也可手动输入任意音色 ID（1.0 音色 `_mars_bigtts` 需把资源 ID 改成 `seed-tts-1.0` 后手动填入）。

其他可调项：语速、音频格式（mp3 / wav / pcm / ogg / opus）、采样率。火山特有的拼接式 JSON 分块流响应已完整解析，长音频合成可用。

## 语音消息与朗读

- **语音输入**：实时转写成文字发送；
- **朗读回复**：回复流式朗读，可随时打断。

## 语音 / 视频通话

::: info 通话按钮的显示条件
聊天页顶栏的通话按钮**只在语音输出（TTS）与语音识别（ASR）都已配置时才会出现**——只配了其中一个时看不到按钮，这是正常现象，把两项都配好即可。
:::

聊天页**顶栏**一键进入通话界面：

1. 对着说话：本地静音检测 → ASR 增量转写 → 停顿后自动发送；
2. 回复流式朗读，可随时打断（说话即停）；
3. 挂断后通话内容折叠成存档卡片留在会话里，便于回看。

视频通话在语音通话基础上加入视频画面；通话存档作为普通消息参与后续上下文。
