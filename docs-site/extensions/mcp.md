# MCP：模型上下文协议

MCP（Model Context Protocol）是连接外部工具与数据源的开放协议。添加 MCP 服务器后，它的工具会出现在助手的工具列表里，AI 按需调用——查数据库、控浏览器、接自家 API，都是标准玩法。

## 两个管理层级

- **全局**：**设置 → 酒馆功能 → 扩展管理 → MCP**——添加与管理 MCP 服务器；
- **助手级**：**助手详情 → MCP**——为当前助手勾选可用的 MCP 服务器与工具。

## 添加服务器

1. 进入 **设置 → 酒馆功能 → 扩展管理 → MCP**；
2. 新建服务器，按服务器类型填写连接信息（SSE / Streamable HTTP 填 URL）；
3. 保存并启用，拉取工具列表确认连接成功；
4. 到 **助手详情 → MCP** 勾选该服务器，工具即对该助手可用。

::: info 关于本地进程型服务器
桌面端常见的 stdio 本地服务器（npx 启动那类）在安卓上无法直接运行——它们需要以远程形式部署（自己的服务器或云函数），再以 SSE / HTTP 方式接入。
:::

## 使用特性

- **OAuth 授权**：支持 OAuth 流程的服务器可直接授权，回调使用 localhost 规避中转 WAF 403；
- **复杂参数**：工具的 `inputSchema` 支持内联 `$ref`，参数复杂的第三方服务器也能正常列出；
- **统一审批**：MCP 工具与内置工具、插件工具共用[审批策略](/settings/huadeng)。

## 使用建议

- 对话里直接说「用某个工具做某事」，工具调用过程在消息下方实时显示；
- 强工具（写数据库、发请求）建议配合「强制确认所有工具调用」策略使用；
- 工具过多时按助手只勾选需要的——工具描述会占上下文，少即是省。
