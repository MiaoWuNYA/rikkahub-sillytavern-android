# 工作区：终端沙箱与项目文件

工作区是应用内的沙箱目录 + 终端环境：AI 在固定目录里读写文件、跑命令，适合把「和 AI 一起做点东西」的素材与产物集中管理。

## 打开方式

**设置 → 酒馆功能 → 扩展管理 → 工作区**。

## 能做什么

- **沙箱目录**：工作区内的文件与真实存储隔离，AI 的文件操作默认限定在工作区内，不碰你的相册和文档；
- **终端多标签**：多个终端会话并行，随时切换；
- **Shell 兼容模式**：对命令语法兼容性做适配，常见 Unix 命令可用；
- **配合文件工具**：AI 通过 `file` 等工具读写工作区文件，配合技能（如「写网页」「整理数据」类说明书）完成完整的小项目。

## 使用建议

- 让 AI「在工作区里新建一个 index.html 并写一个待办页面」，然后自己打开文件检查；
- 敏感目录的写入操作受[审批策略](/settings/huadeng)约束，工作区外的路径会要求确认。

::: tip
工作区是「上游功能全部保留」的一部分——本分支在其上修复了 Shell 兼容性并与本地工具链打通。
:::
