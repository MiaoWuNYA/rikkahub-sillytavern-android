# 技能：给 AI 装载说明书

技能是 Markdown 形式的「说明书包」：对话命中关键词时自动把 `SKILL.md` 注入上下文，让 AI 按说明行事——不依赖模型主动调用。

## 在哪里管理

**设置 → 扩展管理 → 智能体技能**；助手级在 **助手详情 → 扩展管理** 勾选启用。

## 安装技能的三种方式

### 从 GitHub 导入

1. 进入 **设置 → 扩展管理 → 智能体技能**，点右上角的**新建**（加号按钮）；
2. 选择**从 GitHub 导入**，粘贴 GitHub 仓库 URL——应用自动下载仓库根目录中的 `SKILL.md`；
3. 可选填 GitHub Token（提升 API 限额到 5000/小时）；
4. 安装成功后技能出现在列表中，按分类筛选管理；安装来源与整目录哈希会被记录，支持后续更新检测。

技能也可以通过文件管理器直接放进公共目录 `/Rikkahub/skills` 增删。

### 本地导入

把技能文件夹直接导入应用，适合自己写的技能或从别处拿到的压缩包。

### 公共目录

技能目录使用外部存储的 `/Rikkahub/skills`——用任何文件管理器直接增删，改完回来刷新即可。

## 技能的构成

```
我的技能/
├── SKILL.md        # 主说明书：关键词触发后注入的内容
└── (可选脚本/资源)  # SKILL.md 里引用的补充文件
```

- **自动触发**：对话命中技能配置的关键词 → 注入 `SKILL.md`；
- **斜杠命令**：技能可注册命令，出现在输入框斜杠面板；
- **与缓存**：技能注入按「用户轮」冻结，参与[前缀缓存优化](/memory/cache)。

## 与插件的区别

| | 技能 | 插件 |
| --- | --- | --- |
| 形态 | Markdown 说明 + 可选脚本 | QuickJS 沙箱 ZIP |
| 触发 | 关键词自动注入 | AI 主动调用工具 |
| 能力 | 指导 AI 行为 | 扩展 AI 能力（网络、数据、设备） |
| 管理位置 | 设置 → 扩展管理 → 智能体技能 | 设置 → 插件管理 |

两者可以组合：技能教 AI「怎么用」，插件给 AI「能用什么」。
