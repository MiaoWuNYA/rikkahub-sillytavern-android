# 手机增强：设备工具与消息 Bot

让 AI 真正「住」进手机：30 个设备工具供其调用，微信 / QQ 消息可接入指定助手，还能按计划主动找你聊天。

## 设备工具箱（30 个工具）

**开启**：**助手详情 → 本地工具**，勾选设备工具箱。

AI 可调用的能力一览：

| 类别 | 工具 |
| --- | --- |
| 设备状态 | 手电筒 · 震动 · 音量读写 · 亮度读写 · 电量 · 存储 · Wi-Fi / 音频 / 电话 / 传感器信息 |
| 系统操作 | Toast 提示 · 分享 · 壁纸 · 系统通知 · 闹钟 / 计时器 · 音乐控制 · 应用启动 · 打开网页 |
| 信息读取 | 短信读取 · 联系人（列出 / 搜索） · 通话记录 · 定位 |
| 媒体文件 | 媒体扫描 · 文件下载 · 打开文件 |

### 懒发现：不占上下文的工具集

30 个工具如果全部注册会占掉大量上下文。华灯采用**懒发现**：上下文里只注册一个 `device_toolbox` 工具位，AI 先 `action=list` 拉取工具目录（含参数说明与权限授予状态），再 `action=run` 调用具体工具——平时只花一个工具的 token，用到时才有全部能力。

### 权限与审批

- 短信、联系人、通话记录、定位、通知等工具需要对应的系统权限授予；
- `action=list` 免审批；`action=run` 按工具判断，敏感操作需要确认（策略见[安全设置](/settings/huadeng)）。

## 微信 Bot / QQ Bot

把某个已有助手接入消息通道——AI、记忆、工具全部复用该助手，来消息时它替你回复。

**开启**：**设置 → 华灯设置 → 接入与自动化**：

- **微信 Bot**：扫码登录自己的微信号（iLink 协议），HTTP 长轮询收消息自动回复；token 过期自动停服并通知；
- **QQ Bot**：QQ 开放平台官方 API，填入 AppID + AppSecret 即可，WebSocket 网关实时收发，token 自动刷新。

两者**默认关闭**，开启前有隐私风险确认弹窗。

## AI 主动发消息

开启后，AI 会按随机间隔（可设范围）主动找你聊天：

- AlarmManager 精确闹钟 + WorkManager 兜底双通道，到点即发；
- 生成时注入上下文：上次聊天距今多久、当前时间、电量——开场白不再是凭空捏造；
- 正在生成时礼貌放弃，不与你正在进行的对话冲突。

默认关闭，**开启：设置 → 酒馆功能 → 主动消息**。

::: warning 封号风险，请自行评估
微信 Bot 使用非官方协议（iLink 扫码登录），**存在账号被限制或封禁的风险**——建议使用小号，不要在主力微信号上开启。QQ Bot 走官方开放平台 API，风险相对较低，但消息内容仍需遵守平台规范。开启前应用会弹出隐私风险确认，请确认你了解并接受风险后再使用。
:::
