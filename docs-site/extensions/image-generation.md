# 图片生成：文生图工作台

独立的文生图页面：接入支持图像生成的模型后，输入描述即可生成图片，保存到相册或直接插入对话。

## 打开方式

聊天页左侧抽屉 → 点**菜单**（闪光图标）→ **图片生成**。

## 使用

1. **选模型**：页面顶部选择支持图像生成的模型（如 Gemini 的图像模型、DALL·E 系列）；
2. **写描述**：输入画面描述——越具体（主体、风格、构图）效果越稳定；
3. **选比例**：支持 16:9 横屏、9:16 竖屏、1:1 正方形；
4. **生成与保存**：生成中可随时取消；完成后保存到设备或分享。

生成的图片保存在应用存储中，也参与按日清理策略（见[华灯设置](/settings/huadeng)的隐私说明）。

## 对话中生成

聊天里直接让 AI「画一张…」时，支持的模型会通过工具调用生成图片并插入回复——两种方式共用同一个图像模型配置。

::: tip
图像生成按供应商计费，与对话 token 分开计价；生成失败通常是该模型不支持图像输出，切换图像模型即可。
:::
