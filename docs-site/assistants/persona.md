# 人设与导演备注

两者都遵循酒馆官方语义：人设（Persona）定义「你是谁」，导演备注（作者注释）向 AI 传递剧情层面的指示。

## 人设 Persona

**创建**：进入 **设置 → 酒馆功能 → 用户人设**，新建人设——名称 + 描述（你的身份、背景、说话习惯）。

**注入位置**遵循官方五档：

| 位置 | 行为 |
| --- | --- |
| IN_PROMPT | 注入系统提示词区（默认） |
| TOP | 作为独立消息插在上下文最前 |
| BOTTOM | 作为独立消息插在历史末尾 |
| AT_DEPTH | 按指定深度插入历史中 |
| NONE | 不注入（仅保存） |

**绑定助手**：不同助手可绑不同人设——酒馆对话里你是「冒险者」，工作助手面前你是「项目负责人」。绑定后该助手对话自动使用对应人设；`{{persona}}` 宏可引用当前人设内容。

**一键禁用**：临时不想暴露人设时直接关掉，不需要删配置。

## 导演备注（作者注释）

导演备注是一条随对话注入的固定指示。入口：**设置 → 酒馆功能 → 导演备注**（聊天抽屉底部「菜单」里也有快捷入口，或助手级配置）。

**典型用途**：

- 剧情引导：「推进到夜晚场景」「本周目走隐藏线」；
- 写作要求：「每段回复不超过 300 字」「对话用中文，术语保留英文」；
- 输出格式：「每次回复末尾附状态栏」。

### 配置项

| 配置 | 说明 |
| --- | --- |
| 注入间隔 | 每次生成都注入，或每 N 条用户消息注入一次 |
| 注入深度 | 插入历史的深度（0 = 最后一条之后） |
| 注入角色 | user / assistant / system |
| 总开关 | 随时启停，内容保留 |

### 多条导演备注

支持同时维护**多条**导演备注并可多选启用——一条管剧情、一条管文风，按需组合，不必反复改单条内容。

::: tip
导演备注与世界书、正则一样参与[前缀缓存优化](/memory/cache)：同一轮内多次请求的注入位置与内容保持一致。
:::
