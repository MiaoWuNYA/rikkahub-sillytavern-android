# 群聊：多角色同场对话

把多个助手拉进同一个会话，各角色带着各自的人设、提示词与模型同场演出——适合跑团、圆桌讨论或日常群聊。

::: warning 群聊系统正在测试中
群聊功能存在较多问题，目前正在集中修复。遇到崩溃、发言错乱、记忆异常等情况属预期内——建议等修复版本发布后再正式使用。
:::

## 创建群聊

1. 进入 **设置 → 酒馆功能 → 群聊**，点**新建**；
2. 添加成员——从已有助手中选择；
3. 配置发言策略与扩展模式；
4. 回到主界面即可在群聊列表中开始对话。

## 成员管理

每个成员独立配置：

- **提示词与人设**：同一个「世界观」下每个角色有自己的行为方式；
- **模型**：主角用旗舰模型，路人角色用便宜模型——按角色分配预算；
- **禁言**：禁言成员不参与发言抽取，但仍在场（其设定仍影响其他角色的发言）。

## 发言策略：谁来接话

| 策略 | 行为 | 适合 |
| --- | --- | --- |
| NATURAL | AI 根据上下文自己决定谁说话 | 剧情流，让对话自然生长 |
| LIST | 按名单顺序轮流发言 | 圆桌讨论、轮流叙事 |
| POOLED | 加权随机抽取 | 主角戏份多、配角偶尔插话 |
| MANUAL | 每轮由你手动指定发言者 | 精确控场、导演式跑团 |

## 扩展模式与自动接话

- **扩展模式**：控制每轮生成几个回复（单人 / 多人接力等 5 种模式）；
- **自动接话**：角色自动连续对话——轮数 1–10 可设、间隔延迟可设；你的消息随时打断；
- **发言者实时状态**：当前轮到谁、谁被抽中一目了然；
- **持久化**：群聊完整保存，随时回来继续。

## 群聊相关宏与命令

- 宏：`{{groupNotMuted}}`（未禁言成员列表）、`{{notChar}}`（除自己外的成员）可在提示词中使用；
- 斜杠：`/sendas 角色名 内容` 指定角色发言，`/trigger` 触发某角色主动发言。

::: tip
群聊成员同样享受记忆、插件与[缓存优化](/memory/cache)——发言策略的抽取在同一轮内保持稳定，不破坏前缀。
:::
