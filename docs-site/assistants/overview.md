# 助手：角色、模型与设置

助手是华灯的核心概念：一个助手 = 一套人设 + 一个默认模型 + 独立的记忆、工具与扩展配置。会话绑定助手——切换助手即切换人格。

## 助手详情页的八个区块

打开**助手页**，点任意助手进入详情页，共八个配置区块：

| 区块 | 内容 | 详细文档 |
| --- | --- | --- |
| **基础设定** | 名称、头像、模型和参数（温度、上下文、最大回复 token） | 本文 |
| **提示词** | 系统提示、消息模板和正则规则 | [预设·正则](/tavern/preset-regex) |
| **扩展管理** | 提示词注入、世界书和技能等扩展（助手级） | [世界书](/tavern/world-book) |
| **记忆** | 助手记忆和最近的聊天引用 | [记忆系统](/memory/memory) |
| **自定义请求** | 自定义请求头和正文参数 | 本文 |
| **MCP** | 为助手配置 MCP 服务器工具 | [MCP](/extensions/mcp) |
| **本地工具** | 启用本地工具（JavaScript 引擎等） | 本文 |
| **高级记忆设置** | 跳转全局记忆设置 | [记忆系统](/memory/memory) |

## 基础设定要点

- **模型**：该助手使用的对话模型，留空跟随对话中选择；
- **采样参数**：温度越高越发散，角色扮演常用 0.8–1.2；上下文消息数决定带多少历史；
- **上下文与压缩**：长对话超出窗口时按[记忆系统](/memory/memory)的滚动压缩处理。

## 自定义请求

对接特殊服务商时，可按助手配置自定义请求头与正文参数——例如给某个中转站加鉴权头，或强制覆盖某个 JSON 字段。

## 本地工具

设备端执行的工具集：文件读写、命令执行、Python、计算器、数据库查询等。按助手勾选启用，敏感操作受[审批策略](/settings/huadeng)约束。

## 常用操作

- **复制助手**：复制时记忆一并复制，方便基于现有角色微调出平行版本；
- **从角色卡创建**：导入角色卡自动生成对应助手，见[角色卡](/tavern/character-card)；
- **绑定人设**：全局人设（[人设与导演备注](/assistants/persona)）可按助手绑定。
