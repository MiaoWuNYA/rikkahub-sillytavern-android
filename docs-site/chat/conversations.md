# 对话：管理你的会话与消息

所有对话都保存在本机。流式输出、消息编辑、翻译、收藏、全文搜索与导出，都围绕聊天界面完成。

## 会话管理

聊天页**左侧抽屉**（顶栏左上角菜单图标）浏览全部会话，按文件夹归类；文件夹条支持新建，**长按文件夹**可重命名 / 删除。

会话标题默认自动生成（可在**默认模型和提示词**中调整标题模型），点击标题可手动改名。每个会话绑定一个**助手**（角色、提示词与记忆的载体）。

## 消息操作

每条消息下方有一排常驻操作按钮，功能随消息角色变化：

| 操作 | 说明 |
| --- | --- |
| 重新生成 | 以当前上文重新作答，产生新分支。见[分支](/chat/branching) |
| 编辑 | 点击自己发的消息即可编辑，编辑后的内容立即生效于后续对话 |
| 翻译 | 调用翻译模型把消息翻译成目标语言，翻译结果不影响原文 |
| 朗读 | 配置 TTS 后可朗读任意消息；语音通话见[语音与通话](/extensions/speech) |
| 更多操作 | 分享、收藏、删除等收在更多菜单里 |

## 找到历史内容

应用内置中文分词的**全文搜索**，可以按关键词在所有会话中定位消息，不必逐个翻找。生成中的回复若切到后台，前台服务会保持输出不断流。

## 抽屉里的其他工具

聊天抽屉的**菜单**（闪光图标）里还有几个独立工具页：

- **AI 翻译**：独立的翻译工具页，走已配置的翻译模型；
- **图片生成**：文生图工作台，见；
- **提示词查看器**：查看本轮请求发给模型的完整提示词，排查[缓存](/memory/cache)与注入问题时用；
- **导演备注**：快速开关当前会话的导演备注，见[人设与导演备注](/assistants/persona)；
- **收藏**：跨会话查看收藏的消息。

## 导出对话

在会话菜单中选择导出，即可把对话内容保存为文件分享出去；导出时可以选择是否包含思考过程。

::: tip 数据备份
会话、助手、记忆与设置的换机迁移请见[备份](/settings/backup)，建议定期执行。
:::
