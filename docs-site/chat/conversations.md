# 对话：管理你的会话与消息

所有对话都保存在本机。流式输出、消息编辑、翻译、收藏、全文搜索与导出，都围绕聊天界面完成。

## 会话管理

聊天页**左侧抽屉**（顶栏左上角菜单图标）浏览全部会话，按文件夹归类。抽屉里文件夹条右侧是排序按钮，可切换按更新时间 / 创建时间排序；点文件夹条末尾的**新建文件夹**即可新建，**长按文件夹**可重命名 / 删除。**长按任意会话**弹出菜单：置顶、重新生成标题、移动到助手、移动到文件夹、删除。

会话标题默认自动生成（可在 **设置 → 模型与服务 → 模型与服务 → 模型** 中调整标题模型），点击顶栏标题可手动改名。每个会话绑定一个**助手**（角色、提示词与记忆的载体）。

## 消息操作

每条消息下方有一排图标按钮，功能随消息角色变化：

| 操作 | 说明 |
| --- | --- |
| 复制 | 复制该条消息内容 |
| 重新生成 | 以当前上文重新作答，产生新分支。见[分支](/chat/branching)；对自己发的消息会先确认 |
| 朗读 | 配置 TTS 后朗读该条消息，再次点按停止；语音通话见[语音与通话](/extensions/speech) |
| 翻译 | 调用翻译模型把消息翻译成目标语言，翻译结果不影响原文（助手消息） |
| 冒充 | 让 AI 以你的口吻续写（助手消息） |
| 更多 ⋯ | 打开底部菜单：选择复制、网页视图渲染、编辑、分享、创建分支、收藏、删除 |
| 分支切换 | 消息两侧的箭头在兄弟分支之间跳转 |

## 找到历史内容

应用内置中文分词的**全文搜索**，可以按关键词在所有会话中定位消息，不必逐个翻找。生成中的回复若切到后台，前台服务会保持输出不断流。

## 抽屉里的其他工具

抽屉里除了会话列表，还有一排功能入口：

- **聊天历史**：按时间回看历史消息；行尾的**搜索图标**进入跨会话的全文搜索；
- **媒体创作**：文生图 / 视频工作台，可在 **设置 → 主题 → 界面偏好设置 → 聊天界面按钮** 隐藏；
- **翻译**：独立的翻译工具页，走已配置的翻译模型；
- **情侣空间 / 生活空间**：见[情感陪伴](/companion/couple-space)。

抽屉底部的操作栏从左到右是：**助手**（进入助手与角色卡页）、**菜单**（闪光图标，弹出 AI 翻译 / 查看发送的提示词 / 导演备注 / 收藏）、**收藏**、**统计数据**、**设置**（进入设置）。

- **查看发送的提示词**：以网页形式展示本轮请求发给模型的完整提示词，排查[缓存](/memory/cache)与注入问题时用；
- **导演备注**：快速开关当前会话的导演备注，见[人设与导演备注](/assistants/persona)；
- **收藏**：跨会话查看收藏的消息。

## 分享消息

在消息的**更多 ⋯** 菜单里点**分享**，即可把单条消息分享出去；**选择复制**可手动框选要复制的片段。

::: tip 数据备份
会话、助手、记忆与设置的换机迁移请见[备份](/settings/backup)，建议定期执行。
:::
