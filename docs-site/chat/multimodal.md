# 多模态：发送图片、音频与文件

对话不只局限于文字。把图片、音频、视频或文件放进输入框，让具备多模态能力的模型直接理解它们。

## 发送图片

在输入框右下角点 **+**（更多按钮）选择图片或文件，截图也可以直接粘贴进输入框。发送给支持视觉的模型（如 Gemini、Claude、GPT-4o 系列）后，模型可以直接「看懂」截图、照片与图表。

使用不支持视觉的模型时，图片会被跳过——切换视觉模型即可。

## 识别图中的文字

遇到截图里的文字需要提取时，可以交给 OCR：在 **设置 → 模型与服务 → 模型与服务 → 模型** 里配置好 OCR 模型后，应用会把图片转成文字，让不具备视觉能力的模型也能处理截图内容。

## 音频与视频

音频与视频同样可以作为附件发送给支持的模型处理。例如发一段录音让模型总结要点。

## 瞬态内容裁剪：为长对话省 token

图片、音视频与网页搜索结果在提示词里非常占空间。开启**上下文瞬态内容裁剪**后（[华灯设置](/settings/huadeng)），超过两轮的此类内容不再随每次请求发送，取而代之的是一条占位说明与消息编号——模型需要原文时，可通过 `read_history_message` 工具自行取回。

::: tip
图片类长对话开启裁剪后 token 消耗下降明显；对话仍保持连贯，因为 AI 可以按需取回任何被裁剪的原文。开关支持全局与助手级两级配置。
:::
