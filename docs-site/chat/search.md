# 网页搜索：让回答基于最新信息

模型的训练数据有截止日期。开启实时网页访问后，AI 会先搜索再回答，时事、价格、版本号这类问题不再靠编。

## 开启网页搜索

1. **配置搜索服务**：前往 **设置 → 搜索服务**，选择搜索引擎并填入所需的 API Key（不同引擎要求不同），在此选择搜索模式（本地代理 / 服务商内置）；
2. **在对话中使用**：需要最新信息时让 AI「搜一下」，或直接询问时事类问题，AI 会按当前搜索模式联网检索；
3. **查看引用**：回复中的搜索结果会附带来源信息，点按即可查看原文。

## 三种搜索模式

| 模式 | 行为 |
| --- | --- |
| 关闭 | 不联网，纯模型回答 |
| 本地代理 | 由应用本地发起搜索请求，把结果交给模型 |
| 服务商内置 | 交给支持联网的服务商（如 Gemini 内置搜索工具）在服务端完成 |

## 搜索结果不会一直占着上下文

网页搜索结果非常占 token。开启**上下文瞬态内容裁剪**后，超过两轮的搜索结果会自动从请求中移除，替换为占位说明与消息编号；AI 需要原文时可调用 `read_history_message` 取回，不影响连续追问。

::: tip
搜索类长对话建议保持裁剪开启；相关开关在[华灯设置](/settings/huadeng)中，也可按助手单独配置。
:::
