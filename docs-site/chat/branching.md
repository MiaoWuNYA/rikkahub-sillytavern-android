# 分支：从任意消息重新展开

对话不是一条单行道。对任意消息重新生成或修改后，旧的走向不会丢失——它们成为分支，随时可以切回去。

## 重新生成与编辑

任意回复下方点**重新生成**：模型会以同一上文重新作答，产生一个新的候选版本。编辑历史消息同理——点击自己发的消息修改后，后续内容从新版本展开。

## 分支树

每次重新生成或编辑都会形成分支节点。消息两侧的切换箭头可以在兄弟分支之间跳转：

- 回复不满意？重新生成几次，左右切换对比，留下最顺眼的一版。
- 剧情想走另一条线？从中间某条消息分叉，旧线随时切回，互不影响。
- 每条分支都完整保留，包括时间、模型与 token 用量。

::: tip
分支只占极小的存储成本——同一分支内的历史内容不会重复保存，可以放心大胆地分叉试错。
:::

## 配合角色扮演使用

跑团式角色扮演中，分支相当于「存档点」：在关键剧情前分叉一次，之后无论剧情走成什么样，都能回到分叉点重开。配合[斜杠命令](/tavern/macros-slash)的 `/continue` 可以让 AI 从当前分支续写。
