# 备份：换机迁移与数据安全

聊天记录、助手、记忆、插件与全部设置都能备份为文件——换机、刷机、重装不丢数据。入口：**设置 → 数据设置 → 数据备份**。

## 本地备份

1. 进入 **设置 → 数据设置 → 数据备份**；
2. 点**备份**，选择保存位置，生成备份文件；
3. 恢复时选择备份文件，确认后导入。

## 备份包含

备份包含：会话与消息（含分支树）、助手与角色卡、记忆条目、世界书 / 预设 / 正则 / QR、插件与配置、应用设置。

## 与 rikkahub 原版的兼容性

- **rikkahub 原版 → 可以无损导入华灯的备份**：华灯的备份结构是原版的超集，原版会忽略自己不认识的字段；
- **华灯 → 无法导入 rikkahub 原版的备份**：华灯的数据结构包含大量原版没有的实体（酒馆资产、记忆文件、插件数据等），为避免兼容问题，导入原版备份被明确禁止。

从原版迁移到华灯：直接在原版里做一次备份，到华灯里恢复即可；反方向（华灯回原版）不受支持，迁移前请知悉。

::: warning 资源保护
备份导入有资源预算限制（条目数、单条目与总解压大小），防御异常归档耗尽资源；导入采用一致性快照，中断不会留下半套数据。
:::

## 云备份

支持把备份文件同步到你的私有云：

- **WebDAV**：坚果云、Nextcloud 等任何 WebDAV 服务；
- **S3**：AWS S3 及任何兼容 S3 协议的对象存储（阿里云 OSS、Cloudflare R2 等）。

配置好凭据后可一键上传 / 拉取，密钥保存在本机。

## 定期提醒

聊天页抽屉会显示**备份提醒卡片**——距上次备份过久时出现，点按直达备份页。数据无价，建议养成习惯。

## 与应用内更新的关系

更新采用覆盖安装，数据不会丢失；但任何升级前做一次备份都是好习惯，尤其是大版本更新。
