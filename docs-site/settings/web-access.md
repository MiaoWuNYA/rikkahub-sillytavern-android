# Web 访问：在浏览器里继续对话

华灯内置网络对话端：手机与电脑在同一局域网时，可以在电脑浏览器里直接查看与继续手机上的对话——所有数据仍保存在手机本机。

## 开启步骤

1. 进入 **设置 → 模型与服务 → Web 服务器**；
2. 启动服务器；
3. 选择要使用的地址：
   - **本地地址**：`127.0.0.1`，仅手机本机浏览器可用；
   - **局域网地址**：手机在 Wi-Fi 下的 IP，电脑浏览器访问这个；
   - **mDNS 地址**：局域网内以主机名访问（支持 mDNS 的设备免记 IP）；
4. 在电脑浏览器打开该地址，完成配对即可使用。

::: tip 手机热点也能用（本分支增强）
没有路由器也可以：开启手机热点、电脑连上热点后，直接访问**局域网地址**即可。华灯在热点场景下会自动枚举热点网卡（`ap` / `swlan` 接口）获取正确地址——上游原版在热点模式下拿不到地址，这是本分支修补的差异点。

## 可选项

| 选项 | 说明 |
| --- | --- |
| **JWT 鉴权** | 开启后访问需要令牌，防止同局域网的其他人打开你的对话 |
| **仅本机模式** | 只监听 127.0.0.1，外部设备无法连接——只在本机浏览器调试时用 |

## 使用场景

- 电脑上打长文更舒服：大段设定、长回复在浏览器里编辑；
- 双端同一数据源：所有对话、助手与记忆仍保存在手机本机；
- 会话分叉、模型切换等操作与手机端一致。

::: warning
Web 服务仅建议在可信局域网内开启，用完即关；接入不可信网络时保持「仅本机模式」或关闭 JWT 之外的暴露。密钥不会经浏览器暴露。
:::
