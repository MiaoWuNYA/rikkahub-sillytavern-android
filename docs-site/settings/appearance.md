# 外观：颜色、气泡与字体

聊天界面的视觉全部可调。全局主题遵循 Material You；聊天区域另有细粒度自定义与酒馆主题导入。

## 页面层级

```
设置
├── 主题                        ← 四个标签页，直达全部外观设置
│   ├── 主题                    ← 动态取色 / 主题样式 / AMOLED 暗色
│   ├── 颜色                    ← 颜色设置（气泡、背景、文字颜色）
│   ├── 界面                    ← 界面偏好（字体、排版、输入栏、符号按钮）
│   └── 通用                    ← 常规 + 通知 + 网络（APP 图标 / 加载指示器 / 输入框效果）
└── 常规                        ← 与上面「通用」标签同一页
```

## 全局主题

**设置 → 主题**：

- **动态取色**：跟随系统壁纸的 Material You 配色（Android 12+）；
- **主题**：预设色板 + HCT 自定义主题（按色相构建整套配色）；
- **AMOLED 暗色模式**：纯黑背景省电护眼。

## 聊天外观自定义

**设置 → 主题 → 颜色**（颜色、气泡、透明度、背景图）：

- **颜色覆盖**：主色、全局文字、用户 / AI / 思维链气泡、聊天背景、输入框共 7 项自定义颜色（ARGB）；
- **气泡美化**：用户 / AI 气泡背景图 + 圆角 + 主题色遮罩；抽屉背景图；聊天背景图（图片上叠加聊天背景色遮罩）；
- **文字颜色**：正文 / 引用 / 斜体色独立设置，附酒馆橙、暖金、玫红、珊瑚、薰衣草、天蓝、薄荷等预设色板；
- **字体**：聊天字体可导入自定义字体（.ttf / .otf / .ttc），字号比例可调；
- **显示细节**：代码块自动折叠 / 换行、自动折叠思考、聊天列表模型图标等。

## 导入酒馆美化主题

同一页面的**导入**区点**应用酒馆主题**，选择酒馆主题 JSON——配色、背景、气泡圆角、字体按酒馆叠层语义还原，导入前可预览将覆盖的设置项。详见[美化主题](/tavern/theme)。

::: tip
外观自定义与酒馆主题导入作用于同一组设置——导入主题后不满意的项目，直接在同页改回来即可，两者不冲突。
:::
