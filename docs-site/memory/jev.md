# Jev 智能决策：客户端内的隐形判断层

Jev 是一个**只做判断、不生成文本**的专用小模型，作为客户端内部的隐形决策层：记忆筛选与是非判断交给它完成，毫秒级响应，不占用主模型输出。

## 解决什么问题

- 记忆检索靠 embedding 相似度——要么额外调 embedding API（花钱），要么词面匹配不准；
- 弱模型遇到是非题、选择题、打分题爱瞎猜，猜错带偏剧情。

Jev 把这两类「判断型工作」接走：它只输出结论（相关 / 不相关、是 / 否、几分），端到端约 100ms，输出 token 几乎免费。

## 接入步骤

1. 进入 **设置 → 华灯设置 → Jev 智能决策**；
2. 填入 **API 地址、API Key、模型名**——任意 OpenAI 兼容端点均可（建议选一个便宜快速的小模型）；
3. 调节**置信度阈值**滑块；
4. 打开需要的接管开关（见下）。

## 两个接管开关

### 自动记忆筛选

用 Jev 逐条判断「这条记忆与当前对话相关吗」，替代 embedding 相似度检索——省掉 embedding API 调用：

- 候选按时间倒序分批**并行判断**；
- 相关概率过半即注入；
- 身份类记忆（称呼、偏好）即使对话没直接提到也算相关——AI 不会「忘了你是谁」。

### 大模型工具调用（judge）

给主模型挂一个 judge 工具（界面显示「Jev 明断」）：

- 主模型拿不准是非题 / 选择题 / 打分题时直接问 Jev，不再自己猜；
- 系统提示同步注入工具路由说明——弱模型也能发现并使用；
- 界面上能看到每次 judge 的调用与结论。

## 静默回退

Jev 不可用（没配 Key、网络失败、置信度不足）时，记忆与工具全部**回退原有逻辑**：不弹错误、不阻塞对话、不占用一次生成。你不会感知到它的存在——除了回答变快、变省。

::: warning
Jev 是独立 API，请自行评估所接入端点的隐私政策：发给 Jev 判断的是记忆条目摘要与问题本身，不含完整对话历史。
:::
