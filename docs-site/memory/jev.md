# Jev 智能决策：客户端内的隐形判断层

Jev 是一个**只做判断、不生成文本**的专用小模型（TypeSafe System One），作为客户端内部的隐形决策层：是非判断、选择题、打分交给它完成，毫秒级响应，不占用主模型输出。

## 解决什么问题

弱模型遇到是非题、选择题、打分题爱瞎猜，猜错带偏剧情。Jev 把这类「判断型工作」接走：只输出结论（是 / 否、选谁、几分），带校准置信度，端到端约 100ms，输出 token 几乎免费。

## 接入步骤

1. 进入 **设置 → 华灯设置 → Jev 智能决策**；
2. 填入 **API 地址、API Key、模型名**——任意 OpenAI 兼容端点均可（建议选一个便宜快速的小模型）；
3. 调节**置信度阈值**滑块；
4. 打开 **judge 工具**开关。

## judge 工具（界面显示「Jev 明断」）

给主模型挂一个 judge 工具：

- 主模型拿不准是非题 / 选择题 / 打分题时直接问 Jev，不再自己猜；
- 系统提示同步注入工具路由说明——弱模型也能发现并使用；
- 判断请求失败时静默返回失败说明，不会让模型陷入错误处理。

## 静默回退

Jev 不可用（没配 Key、网络失败、置信度不足）时**回退原有逻辑**：不弹错误、不阻塞对话、不占用一次生成。你不会感知到它的存在——除了回答变快、变省。

::: warning
Jev 是独立 API，请自行评估所接入端点的隐私政策：发给 Jev 判断的是问题与被判断的文本片段，不含完整对话历史。
:::
