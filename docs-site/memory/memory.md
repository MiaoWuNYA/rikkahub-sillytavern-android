# 记忆系统：跨对话的持久记忆

记忆功能让助手记住关于你的重要信息——称呼、偏好、剧情进展——并在未来的对话中自动生效。你无需每次重新自我介绍。记忆类功能**默认开启**，三层机制协同工作。

## 在哪里配置

- **助手级**：**助手详情 → 记忆**——该助手的记忆开关、记忆列表与最近聊天引用；
- **全局**：**助手详情页底部的「高级记忆设置」**——固定记忆、跨窗口生活流、长期记忆按需召回的全局参数。

::: tip 进入助手详情页
聊天页左侧抽屉点**助手**（笑脸图标）→ 选择助手进入详情页；当前对话的助手也可从抽屉顶部助手卡片直接进入。
:::

## 三层记忆

| 层 | 作用 | 在哪编辑 |
| --- | --- | --- |
| **固定记忆区** | 独立维护的基础信息，不覆盖角色卡 | 助手记忆页直接编辑 |
| **近期生活流** | 跟随当前对话的动态记忆；其他对话的未读事件自动注入，跨会话连续 | 超过阈值自动后台摘要 |
| **长期记忆** | 词项重叠打分召回，时间越近权重越高 | 自动沉淀 + 手动管理 |

## 语义记忆 RAG

语义记忆分 **FACT（事实）** 与 **EPISODIC（情节）** 两类：

- **事实记忆**：你的称呼、偏好、背景等稳定信息；
- **情节记忆**：发生过的事件，带时间衰减加权——越久远权重越低。

检索用向量嵌入 + 余弦相似度（附中文分词与 CJK 二元组词法兜底），结果按预算注入——只带相关的，不带全部。

### memory_tool

模型可以主动管理记忆：

- `memory_tool` 新增 `list` 读取操作与 fact / episodic 类型区分——AI 先查看已有记忆，再决定写入或更新，避免重复；
- `conversation_search` / `recent_chats` 工具可检索历史对话内容。

## 滚动压缩：突破上下文窗口

长对话超过阈值（按模型上下文窗口自动计算，或手动指定）时，**上下文滚动压缩**把早期消息滚动为摘要：原文保留在本地，仅请求时替换前缀。人设与伏笔不因压缩丢失，对话可以无限继续。

压缩模型在**设置 → 默认模型和提示词**里配置，建议选便宜快速的模型。

::: tip 与缓存配合
压缩摘要采用追加式衔接——token 前缀跨压缩保持稳定，[前缀缓存](/memory/cache)不会因压缩而失效。
:::

## 首轮自动读取记忆

第一轮对话自动注入最近记忆——开局没有相关性查询可用，AI 开局就认识你；之后按相关性按需召回。

## 日常管理

- **查看 / 编辑 / 删除**：助手详情 → **记忆**，按条目操作；
- **手动添加**：不等模型自动提取，在记忆页直接写入条目；
- **最近对话引用**：在助手记忆页开关——把该助手最近的对话列表注入提示词，新会话自然衔接旧话题。

::: warning
删除记忆条目是永久性的。助手在未来的对话中将不会记得该信息，除非手动重新添加或模型再次提取。
:::
