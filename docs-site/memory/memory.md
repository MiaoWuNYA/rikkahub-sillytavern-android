# 记忆系统：跨对话的持久记忆

记忆功能让助手记住关于你的重要信息——称呼、偏好、剧情进展——并在未来的对话中自动生效。你无需每次重新自我介绍。

记忆以**记忆文件**的形式按助手隔离存储，AI 通过一整套记忆工具主动读写，后台整理任务在对话结束后自动沉淀新记忆。

## 在哪里配置

- **助手级**：**设置 → 主题 → 颜色**旁边的记忆入口已并入助手详情——进入**助手详情 → 记忆**查看该助手的记忆文件列表；
- 聊天页左侧抽屉点**助手**（笑脸图标）→ 选择助手进入详情页。

## 记忆文件

每条记忆是一个独立的 Markdown 文件（`memory/` 目录，按助手隔离），带版本号做乐观锁——并发写入冲突时不会静默丢失：

- **读取**：`memory_read` 按路径读文件内容与版本；
- **写入**：`memory_write` / `memory_append` / `memory_str_replace` / `memory_delete` 全套文件操作；
- **整理**：对话结束后后台整理任务自动总结新对话，把值得长期保留的信息写进记忆文件，或合并已有的重复条目。

## 固定记忆与跨窗口生活流

- **固定记忆**：独立维护的基础信息（称呼、偏好），不覆盖角色卡，在助手记忆页直接编辑；
- **跨窗口生活流**：当前对话的动态事件在其他对话的未读注入——多个会话之间剧情保持连续。

## 历史对话检索

`conversation_search` / `recent_chats` 工具可检索历史对话内容，配合记忆文件实现跨会话连续性。

::: tip 记忆文件在哪
记忆文件保存在应用私有目录，随**备份**一起导出；助手复制时默认携带该助手的记忆文件。
:::
