# 角色卡：PNG / V2 / V3 全格式导入

角色卡是酒馆生态的核心资产：一张卡 = 一个完整角色（描述、性格、开场白、示例对话、内嵌世界书）。华灯按 SillyTavern 官方语义完整解析，导入 → 导出**往返无损**——桌面端酒馆的卡拿来就用，改完还能带回去。

## 支持的格式

| 格式 | 说明 |
| --- | --- |
| PNG 卡（含 ccv3） | 角色数据嵌入图片的 tPNG / ccv3 格式，直接选图导入 |
| V2 JSON | `spec: chara_card_v2` 的 JSON 卡 |
| V3 JSON | `spec: chara_card_v3`，含高级字段与内嵌世界书 |
| 风月 / 春水等衍生卡 | 各 AI 站点的酒馆卡格式兼容 |
| 非 PNG 卡 | 自动转 PNG 并做注入宏替换 |

## 导入步骤

1. 打开聊天页**左侧抽屉**（顶栏左上角菜单图标），点**助手**进入助手页；
2. 点右上角**新建助手**（加号按钮）；
3. 在弹出的新建弹窗中，按卡的格式选择对应按钮：
   - **导入酒馆角色卡 (PNG)**——标准 PNG 嵌入卡；
   - **导入酒馆角色卡 (JSON)**——V2 / V3 JSON 卡；
   - **导入春水 AI 角色卡 (JSON)**——春水站的对话导出格式；
   - **导入风月 AI 角色卡 (JSON)**——风月站的卡格式；
   - **从 URL 导入**——粘贴角色卡链接（PNG 或 JSON），应用自动下载；
4. 弹窗底部有开关「**多个开场白合并为同一对话的多条消息**」——部分卡把开场白拆成连续多条，按需开启；
5. 导入成功后助手自动创建，世界书、预设与正则随卡落入对应位置（世界书在助手级扩展里可见）。

::: warning 导入来源
导入的是第三方角色卡时，留意卡内提示词与内嵌脚本的内容来源；从 URL 导入仅支持 http/https 链接，文件大小有限制。
:::

## 保留了哪些字段

字段覆盖 20+（上游原版仅 6 个），桌面端改的字段不会丢：

- 示例对话（`mes_example`）——按 `<START>` 拆成真实 user / assistant 轮次；
- 备选开场白（`alternate_greetings`）——全量导入，聊天中随时切换；
- 多语备注（`creator_notes_multilingual`）、对话后指令（`post_history_instructions`）；
- 角色版本、标签、昵称、资源、`group_only_greetings`、创建 / 修改日期；
- 内嵌世界书（`character_book`）；
- `extensions` 原始 JSON——包括深度提示词的 depth / role 配置。

## 在聊天中使用

- **切换开场白**：新对话时从卡的多开场白中任选一条开局；
- **HTML 展示卡**：卡作者写的 HTML 卡直接渲染，默认展开；卡片内的点击交互照常工作，需要全屏查看时点卡片下方的**眼睛图标**；
- **编辑**：助手详情页与角色卡编辑器可改全部字段、管理内嵌世界书；
- **导出**：一键导出 JSON 或 PNG（数据嵌入图片），回到桌面酒馆照样能跑。

## 常见问题

**导入后对话开头不对？** 检查卡的开场白是否含宏——华灯会对开场白做宏替换，个别卡的开场白依赖酒馆特定宏时可在编辑器里手动微调。

**世界书没生效？** 随卡导入的世界书挂在助手级扩展里，确认对应条目已启用，见[世界书](/tavern/world-book)。
