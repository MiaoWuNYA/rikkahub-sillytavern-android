# 世界书：Lorebook 官方语义引擎

世界书（Lorebook）是酒馆的世界观数据库：每个条目带关键词，对话里命中关键词才注入对应设定——角色背景、地名、势力关系都靠它管理，不占常驻上下文。华灯逐条对齐 SillyTavern 官方 `world-info.js` 语义，桌面端的世界书拿来就用。

## 在哪里管理

世界书有两个管理层级：

- **全局**：**设置 → 扩展管理 → 提示词**——所有助手可用的世界书与提示注入都在这里；
- **助手级**：**助手详情 → 扩展管理**——只对当前助手生效，随角色卡导入的内嵌世界书在这里。

::: tip 预设也从这里导入
酒馆预设 JSON 的导入入口同样在**提示词**页：点**添加世界书**时直接选预设 JSON 文件，应用会识别预设结构（ordered / flat 两种），把 Main Prompt、NSFW、Jailbreak 等条目按官方顺序转成提示注入条目。预设和世界书共用提示注入引擎。
:::

## 导入世界书

1. 进入 **设置 → 扩展管理 → 提示词**；
2. 点**添加世界书**，选择酒馆世界书 JSON 文件（或预设 JSON，见上）；
3. 导入后条目列表可见，可逐条启用 / 停用、编辑、拖拽排序。

## 条目字段：官方语义全覆盖

条目字段从上游 6 个扩展到 30+，逐项对应酒馆官方字段：

| 能力 | 官方字段 |
| --- | --- |
| 四种次级关键词逻辑（任意 / 全部 / 排除任一 / 排除全部） | `selective_logic` |
| 整词匹配 / 正则 / 区分大小写 | `match_whole_words` / `key_regex` / `key_case_sensitive` |
| 条目级扫描深度 | `scan_depth` |
| 常驻激活（蓝灯） | `constant` |
| 跨书分组 + 组权重 + 组覆盖 | `group` / `group_weight` / `group_override` |
| 触发概率 | `probability` / `use_probability` |
| 粘滞 / 冷却 | `sticky` / `cooldown` |
| 延迟激活 | `extensions.delay` |
| 递归排除 / 阻止递归 / 延迟递归 | `exclude_recursion` / `prevent_recursion` / `delay_until_recursion` |
| 预算豁免 | `extensions.ignore_budget` |
| 角色字段匹配 ×6（人设 / 描述 / 性格 / 深度提示词 / 场景 / 备注） | `extensions.match_*` |
| 显示顺序 / 插入位置 / 触发器 | `display_index` / `display_position` / `triggers` |

扫描引擎完整实现官方 `checkWorldInfo` 状态机（INITIAL → 递归 / 最少激活 / 延迟层级循环），带预算、溢出、粘滞、冷却全生命周期；跨书分组按官方规则选出唯一条目（粘滞优先 → 关键词评分 → 组覆盖 → 加权随机）。

## 全局设置

世界书页的**设置**里可调：

| 设置 | 说明 |
| --- | --- |
| 扫描深度 | 默认扫描最近 N 条消息（条目自带 `scan_depth` 时优先用条目的） |
| Token 预算 + 绝对上限 | 世界书注入总预算，超出按优先级裁剪 |
| 最少激活 + 最大递归深度 | 递归扫描的步数约束 |
| 插入策略 | 命中条目插入上下文的位置规则 |
| 溢出提醒 | 预算不够时是否提示 |
| 组评分 | 跨书分组的评分参数 |

## 与缓存的关系

世界书触发按「用户轮」冻结：同一轮内多次请求（重新生成、分支切换）的注入结果一致，[前缀缓存](/memory/cache)不受影响；预算不足时按优先级与触发顺序裁剪，`ignore_budget` 条目豁免。
