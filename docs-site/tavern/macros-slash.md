# 宏与斜杠命令

宏引擎 2.0 对齐酒馆官方语义：宏让角色卡「自己会算」（变量、条件、掷骰），斜杠命令让你在输入框直接操作对话。两者都在聊天输入框直接使用。

## 宏：写在文本里的占位符

宏是 `{{...}}` 形式的占位符，发送请求前会被替换成实际值。60+ 官方宏全量支持；**未知宏原样保留**——不会破坏提示词，Pebble 模板 `{{ message }}` 这类非宏写法不受影响。

### 变量：角色卡的记忆

全局 + 会话级持久化，剧情状态（好感度、金钱、章节）靠它记住：

```
{{setvar::好感度::0}}          设置本对话变量
{{getvar::好感度}}             读取变量
{{addvar::好感度::1}}          变量加值
{{.好感度++}}                  简写自增
{{setglobalvar::章节::3}}      设置全局变量（跨对话）
{{hasvar::好感度}}             判断变量是否存在
{{flushvar::好感度}}           删除变量
```

### 条件：按状态走不同分支

`{{if}} / {{else}}`、比较运算符（`==` `!=` `>` `>=` `<` `<=`）、`&&` / `||`、作用域块、嵌套全部支持；延迟解析只求值选中的分支：

```
{{if .好感度 >= 50}}
她看你的眼神柔和了几分。
{{else}}
她依然保持警惕。
{{/if}}
```

### 随机与时间

| 宏 | 说明 |
| --- | --- |
| `{{pick::A::B::C}}` | 稳定随机选一——同一回合内结果不变 |
| `{{random::A::B::C}}` | 随机选一（缓存友好模式按消息稳定） |
| `{{roll::2d6+1}}` | 掷骰子，支持标准骰子表达式 |
| `{{time::UTC+8}}` | 指定时区时间 |
| `{{datetimeformat::yyyy-MM-dd HH:mm}}` | 自定义时间格式 |
| `{{timeDiff::时间A::时间B}}` | 时间差计算 |

### 对话感知

`{{lastUserMessage}}` `{{lastCharMessage}}` `{{idleDuration}}`（距上一条消息多久）`{{charFirstMessage::N}}`（第 N 条开场白）`{{original}}` 等；配合 `{{char}}` `{{user}}` `{{persona}}` `{{description}}` `{{mesExamples}}` 等 50+ 占位宏，角色卡的所有字段都能引用。

::: tip 随机宏与缓存
缓存友好模式开启时，随机宏按消息稳定取值、时间宏按 5 分钟粒度对齐——历史消息不会每轮重掷，[前缀缓存](/memory/cache)不受影响。
:::

## 斜杠命令：输入框里的控制台

输入框敲 `/` 呼出命令面板，`/help` 列出全部命令与说明。20+ 内置命令：

| 类别 | 命令 |
| --- | --- |
| 角色扮演 | `/impersonate`（AI 以你的口吻起草）、`/continue`（续写）、`/sendas`（指定角色发言）、`/sys`（注入系统消息）、`/sysgen`（注入并生成）、`/trigger`（触发角色主动发言）、`/gen` |
| 变量与随机 | `/listvar` `/setvar` `/getvar` `/addvar` `/incvar` `/decvar` `/flushvar` `/reroll-pick` |
| 角色卡管理 | `/char-update` `/char-duplicate` `/rename-char` |
| 注入 | `/inject`（按位置 / 深度 / 角色注入）、`/prompt`、`/persona` |

技能提供的命令也会自动出现在面板中；[快速回复](/tavern/preset-regex)条目同样在这里一键执行。

## 典型用法

**剧情状态面板**：在角色卡的世界书条目里写 `{{getvar::好感度}}` + 条件宏，让 AI 每轮自动播报状态。

**手动控场**：`/inject position=chat depth=0 role=system 天气转为暴雨` 把环境变化注入下一轮；`/reroll-pick` 重掷上一轮的稳定随机。

**多角色场景**：`/sendas 莉娜 你想先去哪？` 让指定角色主动开口，配合[群聊](/assistants/group-chat)使用。
