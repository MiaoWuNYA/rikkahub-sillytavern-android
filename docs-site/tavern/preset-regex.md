# 预设、正则与快速回复

三样酒馆资产，三个入口——导入前先认清它们各自的位置：

| 资产 | 导入位置 |
| --- | --- |
| 预设 Preset | **设置 → 扩展管理 → 提示词**（添加世界书时选预设 JSON） |
| 正则脚本 Regex | **助手详情 → 提示词 → 消息正则表达式 → 导入酒馆正则脚本** |
| 快速回复 QR | **设置 → 扩展管理 → 快速回复 → 导入酒馆快速回复** |

## 预设 Preset

预设决定「发给模型的提示词长什么样」：Main Prompt、NSFW、Jailbreak、聊天补全等条目的内容、顺序与开关。

::: info 预设没有独立入口，共用世界书按钮
预设的导入入口在世界书页里：**设置 → 扩展管理 → 提示词**，点**添加世界书**时直接选预设 JSON 即可。
:::

**导入**：

1. 进入 **设置 → 扩展管理 → 提示词**；
2. 点**添加世界书**，在文件选择器里选择预设 JSON 文件（世界书 JSON 与预设 JSON 都走这一个按钮，应用自动识别格式）；
3. 导入后预设条目成为**提示注入**项，与世界书条目并列管理。

应用识别两种官方预设结构：

- **ordered**：`prompts` + `prompt_order` 完整结构，按 order 排列生成注入条目；
- **flat**：旧式扁平结构（`main_prompt` / `nsfw` / `jailbreak_prompt` 等字段），自动转成对应注入条目。

每条预设可开关、可排序，注入位置与角色按官方语义保留。

::: tip 预设与世界书共用引擎
导入的预设本质是「常驻的提示注入条目」：不依赖关键词触发，每轮请求按顺序注入。想临时关掉某段预设，在提示词页关掉对应条目即可。
:::

## 正则脚本 Regex

正则脚本对消息文本做查找替换：修格式、加样式、隐藏思维链、重排输出都靠它。**同时作用于展示层与提示词层**——屏幕上看到的和发给模型的一致。

**导入**：

1. 打开对应助手的**详情页 → 提示词**；
2. 找到**消息正则表达式**区块，点**导入酒馆正则脚本**；
3. 选择脚本 JSON（单条或集合均可），提示「已导入 N 条正则」即成功。

导入后每条正则可继续编辑：

| 字段 | 说明 |
| --- | --- |
| 名称 | 列表显示名 |
| 查找正则 | 原文匹配模式（Find） |
| 替换字符串 | 替换内容（Replace），支持 `_ALT` 与宏 |
| OnlyFormat | 只改展示不改进提示词（或反之）的范围开关 |
| 注入深度 | minDepth / maxDepth——只作用于最近 N 条消息 |
| 排序 | 多条正则的执行顺序 |

深度与排序参与[前缀缓存优化](/memory/cache)：按「用户轮」冻结，同一轮内多次请求结果一致。

::: warning 正则是助手表级的
正则挂在**助手**上。换助手后想让同一条正则生效，需要再导入一次（或复制助手时一并带过去）。
:::

## 快速回复 Quick Replies

QR 是可一键执行的预设消息集——把常用操作做成按钮。

**导入**：进入 **设置 → 扩展管理 → 快速回复**，点**导入酒馆快速回复**，选择 QR 集 JSON（识别 `qrList` / `quickReplies` / `message` 字段结构）。

**使用**：在聊天输入框敲 `/` 呼出斜杠面板，QR 条目与内置命令一起出现，点按即执行。QR 内容里可以写[斜杠命令](/tavern/macros-slash)与宏——比如一条「/sendas 莉娜 低头擦拭短剑」就是一键触发的角色动作。
