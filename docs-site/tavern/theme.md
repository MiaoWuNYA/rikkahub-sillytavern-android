# 美化主题：酒馆主题一键导入

SillyTavern 美化主题 JSON 一键导入，聊天界面立刻换装——配色、背景、气泡样式与字体完整还原。已用 **537 个真实主题**全量验证（537/537 解析成功），社区主题基本拿来就能用。

## 导入步骤

1. 进入 **设置 → 偏好设置 → 主题**；
2. 点**聊天外观自定义**（颜色、气泡、透明度、背景图）；
3. 找到**导入**区，点**应用酒馆主题**，选择主题 JSON 文件；
4. 弹出预览对话框，列出这次导入将覆盖的设置项——确认后应用，即刻生效。

主题导入后可随时在**聊天外观自定义**里微调任意一项，或一键还原默认。

## 主题里的东西怎么还原

| 酒馆主题字段 | 映射到华灯 |
| --- | --- |
| 叠层配色（`blur_tint` → `chat_tint` → 气泡色调 → 背景图） | 按酒馆渲染层级合成为不透明近似色，透明气泡主题不会变成整片色块 |
| `custom_css` 背景图 | 识别 `#bg1` / `body` / `#chat` 的 `background-image`，URL 自动下载、data URI 解码 |
| `.mes` / `#chat` 的 `border-radius` | 气泡圆角 |
| `chat_display=1`（气泡模式） | 自动开启 AI 气泡显示 |
| `@font-face` 字体（ttf / otf） | 自动下载并设为聊天字体 |
| `main_text_color` / `quote_color` / `italics_text_color` | 全局文字、引用、斜体色 |
| `font_scale` | 字号比例 |

8 位 hex 按 CSS 规范 `#RRGGBBAA` 解析；woff / woff2 字体忽略（安卓 WebView 兼容性考虑）。

## 导入之后

- 主题作用于**聊天外观层**，与客户端整体外观（Material You 动态取色、HCT 自定义主题）互不影响，见[外观](/settings/appearance)；
- 想微调某个颜色：直接在**外观自定义**里改对应项，不必改主题文件；
- 还原默认：外观自定义页一键重置。

::: warning 来源安全
主题可能包含指向外部地址的背景图与字体下载链接——导入前确认主题来源可信。
:::

## 常见问题

**导入后背景没变？** 该主题的背景写在 `custom_css` 里但选择器不在 `#bg1` / `body` / `#chat` 之列。可以在外观自定义中手动设置聊天背景图。

**字体没生效？** 主题用的 woff / woff2 字体会被忽略；ttf / otf 正常下载生效。
