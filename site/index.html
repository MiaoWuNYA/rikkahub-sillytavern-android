02 · 酒馆兼容

桌面酒馆的资产，原样搬进手机

角色卡、世界书、预设、正则、快速回复与主题六类资产完整迁移，导入导出双向无损，无需 Termux 与 Node.js。

  • 角色卡 · PNG / V2 / V3

    全格式支持，开场白、内嵌世界书与 HTML 展示卡完整保留，往返无损

  • 世界书 · Lorebook

    触发逻辑、排序与预算控制对齐桌面端，附全字段编辑器

  • 预设 · 正则 · 快速回复

    按官方结构导入，展示层与提示词层行为一致

  • 宏 · 60+ 官方宏

    变量持久化、条件分支与掷骰完整可用，未知宏原样保留，不影响提示词

  • 斜杠命令 · 群聊

    20+ 内置命令；多角色群聊支持自定义发言策略与独立配置

  • 美化主题 · 537 个实测

    537 个真实主题验证通过，配色、背景、气泡样式与字体完整还原

不是容器，也不是启动器

原生实现而非容器方案：无 Node 常驻进程，启动更快，资源占用更低。酒馆能力与客户端能力互通——角色卡可直接调用插件、记忆与语音。
